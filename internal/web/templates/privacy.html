Privacy

Ghook is self-hosted software. This instance is run by its operator, on the operator's own server.

Ghook reads Gmail metadata only so it can route notifications to the operator's own webhooks. A message body is fetched only when a webhook is explicitly set to include it, and it is not kept unless the operator turns retention of bodies on.

Ghook does not sell data. Ghook does not share data with anyone except the webhooks the operator configures.

Mail metadata, routes, and secrets stay in the database on the operator's server. There is no Ghook account service and no copy of that database anywhere else.
