Privacy

ghook is self-hosted software that can serve many Google accounts on one instance. This instance is run by its operator, on the operator's own server.

ghook reads Gmail metadata only so it can route notifications to the webhooks you configure. A message body is fetched only when a webhook is explicitly set to include it, and it is not kept unless you turn retention of bodies on.

Each signed-in user sees only their own mailboxes, routes, targets, deliveries and settings. ghook does not sell data. ghook does not share a user's data with anyone except the webhooks that user configures.

Mail metadata, routes, and secrets stay in the database on the operator's server. Target secrets and Google tokens are encrypted at rest. There is no separate ghook account service. You can sign out, or delete your account and data, from the account page.
